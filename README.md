# MNTv Live · prototype

A members-only, hardware-style TV for the people C.Y. Lee backs: a Music Nerd TV add-on.
Give them your network, not your time.

- **Five knobs:** Match (call someone who is grinding), On Air, Timer, Volume, Adlib
- **Weekly drops:** 60-second updates (win, stuck, ask) on a channel guide
- **Skills channel:** chats become founder playbooks you can search, install or export as SKILL.md
- **Tapes, streaks and the portfolio wire**

Static site with no build step. Deploy on Vercel as-is (Framework preset: Other).
All members, updates and playbooks are demo data. Member photos are AI-generated, fictional people.
